# Danh sách các technique ID được sử dụng ver2

Các technique chính

| Technique | Tên | Tactic | Tactic ID | Vai trò |
| --- | --- | --- | --- | --- |
| **T1595** | Active Scanning | Reconnaissance | **TA0043** | Parent cho web reconnaissance |
| **T1595.001** | Scanning IP Blocks | Reconnaissance | **TA0043** | Quét IP/public infrastructure |
| **T1595.002** | Vulnerability Scanning | Reconnaissance | **TA0043** | Quét vulnerability, fingerprint/version/CVE |
| **T1595.003** | Wordlist Scanning | Reconnaissance | **TA0043** | Directory/file/endpoint fuzzing |
| **T1190** | Exploit Public-Facing Application | Initial Access | **TA0001** | Technique quan trọng nhất cho khai thác web |
| **T1110** | Brute Force | Credential Access | **TA0006** | Parent cho tấn công đăng nhập |
| **T1110.001** | Password Guessing | Credential Access | **TA0006** | Một account, nhiều password |
| **T1110.003** | Password Spraying | Credential Access | **TA0006** | Một/số ít password, nhiều account |
| **T1505.003** | Web Shell | Persistence | **TA0003** | Web shell upload/access/persistence |
| **T1499** | Endpoint Denial of Service | Impact | **TA0040** | Parent cho application-layer DoS |
| T1189 | Drive-by Compromise | Initial Access | **TA0001** | XSS với mục tiêu tải mã độc lên máy người dùng |
| T1071.001 | CnC - Application Layer Protocol: Web protocol | Command and Control | TA0011 | Dùng giao thức web để kết nối CnC |

Các Hard negative (cho thêm vào để tăng khả năng cạnh tranh với các technique trên)

| Technique | Tên | Tactic ID | Tại sao cần |
| --- | --- | --- | --- |
| **T1046** | Network Service Discovery | **TA0007 – Discovery** | Phân biệt internal/post-compromise scan với T1595 external reconnaissance |
| **T1078** | Valid Accounts | **TA0001, TA0003, TA0004, TA0005** | Không được nhầm login failure/brute force thành Valid Accounts |
| **T1659** | Content Injection | **TA0001, TA0011** | Hard negative cực quan trọng cho SQLi/XSS/injection |
| **T1210** | Exploitation of Remote Services | **TA0008 – Lateral Movement** | Phân biệt exploit public web app với exploit internal service |
| **T1498** | Network Denial of Service | **TA0040 – Impact** | Phân biệt bandwidth/network flood với application exhaustion |
| T1095 | Non-Application Layer Protocol | TA0011 - CnC | Phân biệt với CnC = Application Layer Protocol. |

Các cặp dễ nhầm lẫn

| Cặp dễ nhầm | Nguyên nhân dễ nhầm | Cách phân biệt chính bằng lời | Đề xuất evidence phân biệt (thay đổi cho phù hợp nếu không có trong schema chuẩn hoá, hoặc nhóm vocab yêu cầu từ alert chuẩn hoá  |
| --- | --- | --- | --- |
| **T1595 Active Scanning ↔ T1046 Network Service Discovery** | Cả hai đều có thể là Nmap, port scan, service probing, nhiều kết nối tới port/host. | **T1595** = reconnaissance/pre-compromise, thường từ ngoài vào public infrastructure. **T1046** = discovery sau khi đã có foothold, thường scan nội bộ/lateral để tìm host/service. | **T1595:** `event.type=network_scan`; `event.action=scan/probe`; `network.zone_direction=inbound`; `target.type=host/service/application`. **T1046:** cùng `network_scan + scan/probe`, nhưng `network.zone_direction=lateral` hoặc source/target đều thuộc vùng internal. Nếu không có zone/post-compromise context → **uncertain**, không ép map. |
| **T1595 ↔ T1595.001 Scanning IP Blocks** | Parent T1595 cũng mô tả scan nói chung; alert scan IP range vẫn match parent rất mạnh. | Chỉ chọn **.001** khi observable chính là **quét nhiều địa chỉ/IP range**, không chỉ nhiều port trên một host. Nếu chỉ biết “có scan” → parent T1595. | `.001`: `event.type=network_scan`, `event.action=scan/probe`; nhiều `target.ip` khác nhau trong cùng pattern/window. Nếu chỉ một destination hoặc alert không chứa scope IP → T1595 fallback. **Lưu ý:** từng alert đơn hiện khó chứng minh “nhiều target.ip” nếu không correlation. |
| **T1595 ↔ T1595.002 Vulnerability Scanning** | Vulnerability scan cũng là active scan nên parent retrieval rất dễ thắng. | **.002** khi mục tiêu của probe là đánh giá **vulnerability/exploitability**, version/config/CVE. Nếu chỉ là generic scan → T1595. | `.002`: `event.type=network_scan`; `event.action=probe/scan`; `producer.rule_name` có vulnerability/CVE/scanner context; `http.path/query/user_agent` cho thấy probe CVE/version; `network.application_protocol=http/tls/...`. Không có evidence vuln-specific → parent. |
| **T1595 ↔ T1595.003 Wordlist Scanning** | Wordlist fuzzing nhìn từ IDS cũng chỉ là rất nhiều HTTP request/probe. | **.003** khi scan lặp dictionary-derived path/file/endpoint/hostname để **tìm content/infrastructure**. Generic probe → T1595. | `.003`: `event.type=network_scan` hoặc `web_request`; `event.action=scan/probe/discover`; `http.path` thay đổi theo directory/file names; `target.type=application`. Pattern `/admin`, `/backup`, `/.git`, extensions... hỗ trợ mạnh. |
| **T1595.001 ↔ T1046** | Đều có thể quét một dải địa chỉ và tìm host/service. | **.001** nhấn vào **public IP-block reconnaissance**; **T1046** nhấn vào **service discovery trong victim environment**. | `.001`: `network.zone_direction=inbound`, target nhiều public IP. **T1046:** `network.zone_direction=lateral`, `event.action=discover/scan`, target internal services. Không có zone context → khó phân biệt chắc chắn. |
| **T1595.002 Vulnerability Scanning ↔ T1190 Exploit Public-Facing Application** | Cùng có CVE URL, payload đặc biệt, HTTP request dị thường; scanner đôi khi gửi payload giống exploit thật. | **.002** hỏi “có vulnerable không?”; **T1190** là request **cố trigger/exploit weakness để đạt access/effect**. | `.002`: `event.type=network_scan`; `event.action=probe/scan`; rule thiên về `scan`, `vulnerability`, `fingerprint`; nhiều probe/check. **T1190:** `event.type=web_request`; `event.action=exploit`; `target.type=application`; `http.query/path` chứa exploit payload; exploit-oriented rule signature. `http.status_code=2xx` chỉ là support, **không chứng minh success**. |
| **T1595.003 Wordlist Scanning ↔ T1110 Brute Force** | MITRE cũng lưu ý Wordlist Scanning dùng brute-forcing/crawling tương tự Brute Force; cả hai có thể là nhiều request lặp lại. | **T1595.003** brute-force **resource/content names**; **T1110** brute-force **credentials**. | `.003`: `event.action=scan/probe/discover`; nhiều `http.path`; không có authentication semantics. **T1110:** `event.type=authentication`; `event.action=login/authenticate`; `event.outcome=failure`; `http.status_code=401/403`; path kiểu `/login`, `/auth`. |
| **T1110 Brute Force ↔ T1110.001 Password Guessing** | Parent và sub-technique dùng gần như cùng evidence authentication failure. | Nếu biết rõ **một account + nhiều password guesses** → `.001`. Nếu chỉ thấy repeated failures mà không đủ account/password pattern → **T1110 parent**. | Cả hai: `event.type=authentication`, `event.action=login/authenticate`, `event.outcome=failure`, `http.status_code=401/403`. `.001` cần thêm `source.user`/target account ổn định + nhiều attempts. Với schema hiện tại và single-alert mapping, thường **không đủ để xuống sub-technique**. |
| **T1110.001 Password Guessing ↔ T1110.003 Password Spraying** | Đều tạo nhiều authentication failures, cùng IP, cùng endpoint. | `.001` = **ít account / nhiều password trên account đó**. `.003` = **một/số ít password trải trên nhiều account**. | Cần `event.type=authentication`, `event.action=login`, `event.outcome=failure` **và identity/cardinality evidence** từ `source.user`/account. Với một alert đơn nếu không mang account-pattern → **không thể phân biệt đáng tin cậy**; fallback T1110. |
| **T1110 Brute Force ↔ T1078 Valid Accounts** | Cùng liên quan login/authentication; retrieval có thể thấy “credential”, “account”, “login”. | **T1110** = đang thử credential, thường failed/repeated. **T1078** = credential **hợp lệ đã được sử dụng** để access. | **T1110:** `event.type=authentication`, `event.action=login/authenticate`, `event.outcome=failure`, `http.status_code=401/403`. **T1078:** `event.type=authentication`, `event.action=login/authenticate`, `event.outcome=success`, response không phải auth rejection. Chỉ có failures → negative/exclusion cho T1078. |
| **T1190 Exploit Public-Facing Application ↔ T1659 Content Injection** | Tên “Content Injection” rất dễ khiến SQLi/XSS/command injection bị map nhầm. | **T1190** = attacker gửi exploit input **vào ứng dụng public-facing**. **T1659** = adversary **chèn/sửa nội dung trên communication channel/traffic** để tác động bên nhận. | **T1190:** `event.type=web_request`, `event.action=exploit`, `target.type=application`, HTTP payload/path/query. **T1659:** cần behavior như `event.action=inject_content`/`intercept` nếu vocab bổ sung; traffic modification/intermediary evidence. Nếu chỉ thấy SQLi/XSS request gửi tới server → **không dùng T1659**. |
| **T1190 ↔ T1210 Exploitation of Remote Services** | Cả hai đều là exploitation qua network tới một service. | **T1190** = khai thác **public-facing application** để initial access. **T1210** = khai thác **remote service để lateral movement**, thường từ một host đã ở trong victim network sang host khác. | **T1190:** `event.type=web_request`; `event.action=exploit`; `target.type=application`; protocol `http/tls`; direction inbound/public-facing. **T1210:** `event.action=exploit`; `target.type=service/host`; protocol như `smb/rdp/ssh/...`; `network.zone_direction=lateral`. Không có lateral/internal context → không nên chọn T1210 chỉ vì exploit service. |
| **T1190 ↔ T1189 Drive-by Compromise** | Cả hai có thể liên quan web/XSS và đều thuộc Initial Access. | **T1190**: attacker **khai thác server/application của victim**. **T1189**: attacker lợi dụng website/content để **compromise người truy cập/client**. | **T1190:** `network.direction=to_server`, `event.action=exploit`, target application/server, malicious `http.query/path`. **T1189:** cần `to_client`, malicious response/content, target client/user rather than server. Với alert chỉ thấy XSS payload gửi tới web server → chưa đủ để kết luận T1189. |
| **T1190 ↔ T1505.003 Web Shell** | Web shell thường xuất hiện ngay sau web exploit, cùng HTTP path và cùng web server. | **T1190** = hành vi **khai thác để vào**. **T1505.003** = web shell **đã được đặt hoặc được truy cập để duy trì/điều khiển foothold**. | **T1190:** `event.action=exploit`, request exploit payload. **T1505.003:** `event.type=web_request/service_access`; `event.action=connect` hoặc action web-shell chuyên biệt nếu vocab bổ sung; `http.path` trỏ tới `.php/.jsp/.aspx` shell bất thường; repeated access đến shell endpoint. Nếu chỉ upload suspicious file mà không biết là web shell → evidence còn yếu. |
| **T1498 Network DoS ↔ T1499 Endpoint DoS** | Cả hai biểu hiện flood, traffic spike và service unavailable. | **T1498** làm nghẽn **network/bandwidth/protocol infrastructure**. **T1499** làm cạn **resource của endpoint/application/service**. | Cả hai: `event.action=flood`, `event.outcome=unknown`, packet/byte counters. **T1498:** rất lớn `network.packets_to_target`, `bytes_to_target`, nhiều network-level traffic, không cần HTTP. **T1499:** `target.type=application/service/host`, `network.application_protocol=http/...`, nhiều request tới một service/endpoint; HTTP/resource exhaustion context. Một flow đơn thường chỉ support, không đủ chứng minh DoS impact. |
| **T1071.001 Web Protocols ↔ T1095 Non-Application Layer Protocol** | Cả hai đều là C2 qua network và có thể cùng nhìn giống persistent communication. | **T1071.001** dùng **HTTP/HTTPS/WebSocket/application-layer web protocol** cho C2. **T1095** dùng protocol bên dưới/non-application layer như ICMP/raw TCP/UDP/SOCKS. | **T1071.001:** `event.type=network_communication`; `event.action=connect`; `network.application_protocol=http/tls`; HTTP fields xuất hiện. **T1095:** `event.type=network_communication`; `event.action=connect`; `network.application_protocol=unknown`; `network.transport_protocol=icmp/tcp/udp`; không có HTTP/DNS/etc app semantics. |
